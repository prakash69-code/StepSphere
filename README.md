# 👟 StepSphere – Premium Footwear E-Commerce Website

StepSphere is a modern, responsive e-commerce website designed for showcasing and selling premium footwear products.  

This project demonstrates front-end web development using **HTML, CSS, and JavaScript**, with a clean UI, structured navigation, and user-friendly experience.

---

## 🌐 Project Overview

StepSphere is a fully designed multi-page e-commerce website that includes:

- 🏠 Home Page
- 🛍 Product Listing Page
- 🔥 Popular Products Page
- 📄 Product Detail Pages
- 📰 Blog & Blog Articles
- 🔬 Research Page
- 👥 About Us Page
- 👤 Login & Signup Page
- 🎨 Individual Portfolio Pages

The website focuses on:
- Clean UI/UX
- Responsive design
- Structured navigation
- Modern e-commerce layout
- Realistic product display

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/stepsphere.git
```

2. Open the project folder.

3. Open `Home.html` inside the `HTML` folder in your browser.

No server required — this is a static front-end project.
